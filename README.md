# PetVida - Clínica Veterinária e Estética Animal

Sistema web desenvolvido para a Clínica PetVida como projeto da disciplina de Design Profissional.

## Sobre o projeto

A PetVida é uma clínica veterinária e centro de estética animal que oferece serviços como consultas, vacinação, pequenas cirurgias, banho e tosa.

O projeto foi criado para facilitar a organização dos agendamentos e das informações dos tutores, pets e atendimentos realizados pela clínica.

## Problema identificado

Atualmente, a clínica utiliza uma agenda de papel para organizar os atendimentos. Com o aumento da quantidade de serviços, esse método pode causar alguns problemas, como:

* Conflitos de horários;
* Esquecimento de consultas, vacinas e banhos;
* Horários disponíveis que acabam não sendo utilizados;
* Dificuldade para encontrar históricos de atendimento;
* Perda de tempo da equipe da recepção;
* Dificuldade para organizar os serviços veterinários e de estética.

## Solução proposta

Foi criado um sistema web para reunir as principais informações da clínica em um único local.

O sistema foi dividido em cinco áreas:

### Dashboard

Mostra um resumo dos atendimentos do dia, como consultas, banhos e tosas, vacinações e horários disponíveis.

### Agenda

Apresenta os atendimentos organizados por horário, mostrando o pet, o tipo de atendimento, o profissional responsável e a situação do agendamento.

### Tutores

Reúne os dados dos responsáveis pelos animais, facilitando a consulta dessas informações.

### Pets

Mostra os animais cadastrados, seus tutores e algumas informações relacionadas aos atendimentos.

### Histórico

Permite consultar registros anteriores dos atendimentos realizados para cada pet.

## Justificativa da solução

A escolha de um sistema web está relacionada à necessidade de melhorar a organização das informações utilizadas pela equipe da clínica.

Ao reunir os dados em um único sistema, a recepção consegue consultar os agendamentos, tutores, pets e históricos com mais facilidade, diminuindo a dependência da agenda de papel e dos arquivos físicos.

O projeto também pode receber novas funções futuramente, como cadastro de clientes, banco de dados, notificações e lembretes para consultas, vacinas e retornos.

## Design

A interface utiliza tons de rosa, lilás e branco.

As cores foram escolhidas para criar uma aparência relacionada ao cuidado e ao atendimento de animais, mantendo também uma interface simples e organizada.

O menu superior permite acessar as diferentes áreas do sistema de forma rápida.

## Tecnologias utilizadas

* HTML5
* CSS3
* Git
* GitHub

## Protótipo

O sistema possui cinco áreas principais:

1. Dashboard
2. Agenda
3. Tutores
4. Pets
5. Histórico

Todas as áreas estão organizadas em uma única página HTML. O menu superior permite navegar entre as seções.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Utilize o menu superior para acessar as áreas do sistema.

## Segurança

O projeto não utiliza senhas, tokens, chaves de API ou outras credenciais.

O arquivo `.gitignore` foi incluído para evitar o envio de arquivos que não precisam fazer parte do repositório.
